# Changelog - GeoServiço-CLIPPER\n\nTodas as mudanças notáveis neste projeto serão documentadas neste arquivo.\n\n## [1.0.0] - 2026-02-17\n\n### Adicionado\n- ✨ Versão inicial do plugin GeoServiço-CLIPPER\n- 🎯 Integração com Google Earth Engine para acesso a dados MapBiomas\n- 📦 Suporte a MapBiomas Collection 10 (1985-2024)\n- 🗺️ Interface gráfica completa para seleção de camadas e parâmetros\n- 📊 Recorte de imagens usando máscara vetorial\n- 💾 Exportação automática de resultados como camadas QGIS\n- 🔐 Autenticação segura no Google Earth Engine\n- 📝 Sistema de log detalhado\n- 🎨 Ícone personalizado do plugin\n- 📚 Documentação completa (README, INSTALL, EXAMPLES)\n- 🧪 Testes unitários\n- 🔍 Validador de estrutura do plugin\n- ⚙️ Integração com QGIS Processing Framework\n- 📋 Suporte a múltiplas geometrias\n- 🔄 Reprojeção automática de dados\n- 📈 Barra de progresso com feedback em tempo real\n\n### Funcionalidades Principais\n\n#### Interface do Plugin\n- Seletor de camada vetorial (máscara)\n- Seletor de anos disponíveis (1985-2024)\n- Seletor de coleção MapBiomas\n- Opções de reprojeção e visibilidade de camadas\n- Especificação de caminho de saída\n- Abas para Configuração, Informações e Log\n\n#### Integração Earth Engine\n- Autenticação via Google OAuth\n- Validação de credenciais\n- Acesso a dados MapBiomas Collection 10\n- Recorte de imagens por geometria\n- Exportação para GeoTIFF\n- Tratamento de erros robusto\n\n#### Processamento de Dados\n- Suporte a múltiplas geometrias\n- Conversão de CRS automática\n- Cálculo de extensão de camada\n- Validação de dados de entrada\n- Processamento em thread separada\n\n#### Documentação\n- README.md com visão geral e instruções\n- INSTALL.md com guia passo-a-passo\n- EXAMPLES.md com casos de uso práticos\n- Docstrings em todas as classes e funções\n- Comentários explicativos no código\n\n### Arquivos Inclusos\n- `metadata.txt` - Metadados do plugin\n- `__init__.py` - Ponto de entrada\n- `geosservico_clipper.py` - Classe principal\n- `dialog.py` - Interface gráfica\n- `earth_engine_handler.py` - Integração com Earth Engine\n- `utils.py` - Funções utilitárias\n- `processing_provider.py` - Integração com Processing\n- `test_plugin.py` - Testes unitários\n- `validate_plugin.py` - Validador de estrutura\n- `icon.png` - Ícone do plugin\n- `requirements.txt` - Dependências Python\n- `README.md` - Documentação principal\n- `INSTALL.md` - Guia de instalação\n- `EXAMPLES.md` - Exemplos de uso\n- `CHANGELOG.md` - Este arquivo\n- `.gitignore` - Configuração Git\n\n### Requisitos\n- QGIS 3.40 ou superior\n- Python 3.8 ou superior\n- earthengine-api\n- numpy\n- GDAL\n- Conta Google com acesso ao Earth Engine\n\n### Dependências Python\n```\nearthengine-api>=0.1.400\nnumpy>=1.21.0\nGDAL>=3.4.0\nrequests>=2.28.0\n```\n\n### Compatibilidade\n- ✅ QGIS 3.40\n- ✅ QGIS 3.41 (esperado)\n- ✅ Windows 10/11\n- ✅ Linux (Ubuntu 20.04+, Debian, Fedora)\n- ✅ macOS 10.15+\n\n### Conhecidos Limitações\n- Requer conexão com internet para acessar Earth Engine\n- Processamento de geometrias muito grandes pode ser lento\n- Alguns CRS podem não ser suportados automaticamente\n- Limite de tamanho de arquivo de saída depende do Google Drive\n\n### Próximas Melhorias Planejadas\n- [ ] Suporte a outras coleções MapBiomas (Amazônia, Cerrado, etc.)\n- [ ] Cache local de imagens processadas\n- [ ] Análise temporal automática\n- [ ] Integração com banco de dados\n- [ ] Suporte a múltiplas regiões simultâneas\n- [ ] Exportação em múltiplos formatos\n- [ ] Interface de configuração avançada\n- [ ] Suporte a operações batch\n\n### Agradecimentos\n- MapBiomas pelo acesso aos dados\n- Google Earth Engine pela plataforma\n- Comunidade QGIS pelo suporte\n- Tecno.
