# Quick Start - GeoServiço-CLIPPER\n\n## ⚡ Início Rápido em 5 Minutos\n\n### 1️⃣ Instalar o Plugin (2 minutos)\n\n**Windows:**\n```\n1. Baixe: geosservico_clipper_v1.0.0.zip\n2. Extraia em: C:\\Users\\[SEU_USUARIO]\\AppData\\Roaming\\QGIS\\QGIS3\\profiles\\default\\python\\plugins\\\n3. Renomeie a pasta para: geosservico_clipper\n4. Reinicie o QGIS\n```\n\n**Linux/macOS:**\n```bash\ncd ~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/\nunzip ~/Downloads/geosservico_clipper_v1.0.0.zip\nmv geosservico_clipper-main geosservico_clipper\n```\n\n### 2️⃣ Instalar Dependências (1 minuto)\n\nAbra o **Console Python** do QGIS e execute:\n\n```python\nimport subprocess\nimport sys\nsubprocess.check_call([sys.executable, '-m', 'pip', 'install', 'earthengine-api'])\n```\n\n### 3️⃣ Autenticar no Earth Engine (1 minuto)\n\n1. Abra o plugin: **Plugins** → **GeoServiço-CLIPPER** → **GeoServiço-CLIPPER - Recortar MapBiomas**\n2. Clique em **\"Autenticar no Earth Engine\"**\n3. Faça login com sua conta Google\n4. Autorize o acesso\n5. Copie o código de autorização\n6. Cole no plugin e clique **OK**\n\n### 4️⃣ Usar o Plugin (1 minuto)\n\n1. **Importe uma camada vetorial** (shapefile, GeoJSON, etc.)\n2. **Abra o plugin**\n3. **Configure:**\n   - Camada Vetorial: Selecione sua camada\n   - Ano: 2024 (ou outro ano entre 1985-2024)\n   - Coleção: Collection 10\n4. **Clique em \"Recortar MapBiomas\"**\n5. **Aguarde** (pode levar alguns minutos)\n6. **Pronto!** A imagem recortada aparecerá como nova camada\n\n---\n\n## 🎯 Exemplo Prático\n\n### Cenário: Analisar uso do solo em uma propriedade rural\n\n**Passo 1:** Prepare seus dados\n```\n- Abra QGIS\n- Importe o shapefile da propriedade\n```\n\n**Passo 2:** Abra o plugin\n```\nPlugins → GeoServiço-CLIPPER → GeoServiço-CLIPPER - Recortar MapBiomas\n```\n\n**Passo 3:** Configure\n```\nCamada Vetorial: propriedade_rural\nAno: 2024\nColeção: Collection 10\nArquivo de Saída: (deixe como temporário)\n```\n\n**Passo 4:** Processe\n```\nClique em \"Recortar MapBiomas\"\nAguarde a conclusão\n```\n\n**Passo 5:** Analise\n```\nA imagem MapBiomas recortada aparecerá como nova camada\nUse a ferramenta de seleção para analisar classes\nConsulte a legenda na aba \"Informações\"\n```\n\n---\n\n## 📚 Próximos Passos\n\n- 📖 Leia [README.md](README.md) para mais detalhes\n- 🔧 Consulte [INSTALL.md](INSTALL.md) para troubleshooting\n- 💡 Veja [EXAMPLES.md](EXAMPLES.md) para mais exemplos\n- 📝 Confira [CHANGELOG.md](CHANGELOG.md) para histórico\n\n---\n\n## ❓ Dúvidas Frequentes\n\n### P: Preciso de uma conta Google?\n**R:** Sim, e ela deve ter acesso aprovado ao Google Earth Engine.\n\n### P: Quanto tempo leva para processar?\n**R:** Depende do tamanho da geometria. Geralmente 1-5 minutos.\n\n### P: Posso processar múltiplos anos?\n**R:** Sim! Repita o processo para cada ano desejado.\n\n### P: Os dados são salvos automaticamente?\n**R:** Sim, como camada QGIS. Você pode exportar em vários formatos.\n\n### P: Qual é a resolução dos dados?\n**R:** 30 metros (resolução do Landsat).\n\n---\n\n## 🆘 Precisa de Ajuda?\n\n- 📧 Email: contato@geoservico.com.br\n- 🐛 Issues: https://github.com/geosservico/geosservico-clipper/issues\n- 📚 Docs: https://github.com/geosservico/geosservico-clipper\n\n---\n\n**Desenvolvido com ❤️ para a comunidade geoespacial brasileira**\n
