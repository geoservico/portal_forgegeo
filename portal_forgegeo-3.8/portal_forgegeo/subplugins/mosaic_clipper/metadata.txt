    0.0.9 - Reduzido o número de cenas Sentinel-2 avaliadas simultaneamente para evitar o erro de agregações concorrentes do Earth Engine.

    0.0.5 - Correcao definitiva: Extracao robusta de coordenadas para MultiPolygon. Multiplas estrategias de conversao para maxima compatibilidade.
    0.0.4 - Correcao: Suporte para geometrias MultiPolygon. Usa bounding box para converter MultiPolygon em Polygon valido para EE.
    0.0.3 - Simplificacao: Remocao da exportacao para Google Drive. Foco exclusivo em download local e carregamento automatico de raster no QGIS.
    0.0.2 - Correcao: Adicionar campo Project ID obrigatorio para inicializacao do GEE. Implementar carregamento automatico de raster no QGIS apos download.
    0.0.1 - Versao inicial do plugin Mosaic Clipper com integracao GEE e serie temporal Landsat (2000-2025).
